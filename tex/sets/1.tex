\section{Sampling from a distribution with the inversion method}%
\label{ex:012}

\begin{sourcefiles}
  \item[Source codes] src/012\_inversion\_power34.c
  \item[Analysis scripts] src/012-4\_inversion\_method.R
  \item[Executables] exe/012\_inversion\_power34
\end{sourcefiles} 

The idea is to sample from the probability distribution $\rho_n(x) = c x^n$ in
$[0, 1]$.  First, using the normalization condition we can find out what $c$
should be:
\begin{equation}
  1 = \int_{0}^{1} cx^n \, dx = \frac{c}{n + 1} \implies c = n + 1.
\end{equation}
Then, we find the expression of the associated cumulative density function:
\begin{equation}
  F_n(x) = (n + 1) \int_{0}^{x} y^n \, dy = x^{n + 1},
\end{equation}
and invert it:
\begin{equation}
  u = x^{n + 1} \implies x = u^{1 / (n + 1)}.
\end{equation}
So, we just have to sample a random floating point number between $0$ and $1$
and raise it to the power of $1 / (n + 1)$ to get $x \sim (n + 1) x^n$. Results
from a sampling of \num{50000} iterations for $n = 3, 4$ are shown in
\figref{fig:012}.

\begin{figure}
  \centering
  \includegraphics{img/012.png}
  \caption{histogram of \num{50000} samples from $\rho_n(x) = c x^n$, $x \in [0,
    1]$, for $n = 3$ (up) and $n = 4$ (down), obtained with the inversion method
    for \exref{ex:012}. The theoretical distribution is overlaid with a solid
    line.}
  \label{fig:012}
\end{figure}

\section{Another sampling with the inversion method}\label{ex:013}

\begin{sourcefiles}
  \item[Source codes] src/012\_inversion\_power2.c

  \item[Executables] exe/012\_inversion\_power2

I slightly modified the code from the previous exercise, since $c$ is different
now. The distribution is $\rho(x) = cx^2$ with $x\in [0, 2]$, so:
\begin{equation}
  1 = \int_{0}^{2} cx^2 \, dx = \frac{8}{3}c \implies c = \frac{3}{8}.
\end{equation}
The cumulative is then
\begin{equation}
  F(x) = \frac{3}{8} \int_{0}^{x} y^2 \, dy = \frac{x^3}{8} \implies x = 2
  u^{1/3}.
\end{equation}
Once again, you can see the comparison between a \num{50000}-points histogram
and the theoretical curve in \figref{fig:013}.

\end{figure}

\section{Additional exercises on the inversion method}\label{ex:014}

\begin{sourcefiles}
  \item[Source codes] src/014a\_inversion\_exp.c, src/014b\_inversion\_exp2.c,
    src/014c\_inversion\_powerlaw.c
  \item[Analysis scripts] src/012-4\_inversion\_method.R
  \item[Executables] exe/012\_inversion\_exp, exe/014b\_inversion\_exp2,
    exe/014c\_inversion\_powerlaw
\end{sourcefiles} 

The first exercise here asked to sample from $\rho_1(x) = \mu e^{-\mu x}$, with
$x \in [0, \infty)$. The cumulative and the sampling rule are then
\begin{equation}
  F_1(x) = \mu \int_{0}^{x} e^{-\mu y}\, dy = \mu (1 - e^{-\mu x}) \implies
  x = -\log(1 - u) / \mu.
\end{equation}
I ran \num{50000} samples as before, choosing $\mu = 2$; see \figref{fig:014a}.

\begin{figure}
  \centering
  \includegraphics{img/014a.png}
  \caption{histogram of \num{50000} samples from $\rho(x) = 2 e^{-2x}$, $x
    \in [0, \infty)$, otained with the inversion method for the first part of
    \exref{ex:014}. The theoretical distribution is overlaid with a solid line.}
  \label{fig:014a}
\end{figure}

The second distribution was $\rho_2(x) = 2x e^{-x^{2}}$, $x \in [0, \infty)$.
Cumulative and sampling rule:
\begin{equation}
  F_2(x) = 2 \int_{0}^{x} e^{-y^{2}}\, dy = 1 - e^{-x^{2}} \implies x =
  \sqrt{-\log(1 - u)}.
\end{equation}
A histogram of \num{50000} samples is shown in \figref{fig:014b}.

\begin{figure}
  \centering
  \includegraphics{img/014b.png}
  \caption{histogram of \num{50000} samples from $\rho(x) = 2x e^{-x^{2}}$, $x
    \in [0, \infty)$, otained with the inversion method for the second part of
    \exref{ex:014}. The theoretical distribution is overlaid with a solid line.}
  \label{fig:014b}
\end{figure}

The last distribution was $\rho_{3}(x) = c(a + bx)^{-n}$, with $x \in [0,
\infty)$ and $n > 1$. The normalization constant is given by
\begin{equation}
  1 = \int_{0}^{\infty} c(a + bx)^{-n}\, dx = \frac{a^{1-n} c}{b(n - 1)}
  \implies c = b(n - 1) a^{n - 1}.
\end{equation}
By integrating we obtain
\begin{equation}
  F_{3}(x) = c \int_{0}^{x} (a + by)^{-n}\, dy = \frac{c}{b(1 - n)} \left[(a +
  bx)^{1-n} - a^{1-n}\right] = 1 - a^{n-1}(a + bx)^{1-n},
\end{equation}
from which we can sample with
\begin{equation}
  u = 1 - a^{n-1}(a + bx)^{1-n} \implies x = \frac{a}{b} \left[(1 - u)^{1 /
  (1-n)} - 1\right].
\end{equation}
I chose $a = 1/2$, $b = 1/10$ and $n = 4$ -- resulting in $\rho_{3}(x) = 375 /
(5 + x)^{4}$ -- for a run of \num{50000} samples, shown in \figref{fig:014c}.

  \label{fig:014c}
